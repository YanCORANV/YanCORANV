### SmolVLA–LIBERO — Language Robustness & Policy Evaluation
Independent Research Project
[Code & Results](https://github.com/YanCORANV/SmolVLA-LIBERO)

Investigating how changes in natural language instructions affect VLA policy behavior on LIBERO manipulation tasks.
- Implemented and evaluated fine-tuning, language augmentation, Paired Behavior Cloning, and frozen-teacher flow consistency.
- Conducted a 153-rollout frozen final evaluation. Paired BC achieved 94.1% observed canonical success, compared with 70.6% for canonical-only fine-tuning, but did not improve success on unseen paraphrases.
- Documented experimental protocols, failure analyses, and reproducible results.
